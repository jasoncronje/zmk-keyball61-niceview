Pointer aim test

Click each red target as fast as you comfortably can. The dashed ring shows where the next one will appear. The page measures how far you overshoot and how many strokes each move takes at short, mid and long distances. Takes about 90 seconds. Esc aborts.

Keep the browser window the same size between runs so distances match. macOS pointer acceleration should stay off (the firmware does it).

Result

    By distance

    Past target: how far beyond the target centre the pointer went, as % of the distance (median). Big overshoots: moves that went more than 10% of the distance past the far edge. Strokes: separate pushes to get there. A trackball needs more than one on long moves; that's fine unless there's no overshoot at all.

    Overshoot vs peak speed
    shortmidlongline: average per speed band

    A flat line near 0 means the acceleration curve matches your hand. Rising to the right: fast moves carry too far.

    Paths, aligned to the target (target at right)

    Every move rotated so it runs left to right and scaled so the target sits at the dashed line. Loops past the line are overshoots.
