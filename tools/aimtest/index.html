Pointer aim test

Click each red target as fast as you comfortably can. The page measures where your first push stops, before you correct, at short, mid and long distances. Takes about 90 seconds. Esc aborts.

Keep the browser window the same size between runs so distances match. macOS pointer acceleration should stay off (the firmware does it).

Result

    Where the first push stopped, by distance

    Landing error: + past the target, − short of it, as % of the distance. Within ±5% is good. Passed: how often the path went beyond the far edge. Fixes: extra pushes after the first.

    Landing error vs peak speed
    shortmidlongline: average per speed band

    A flat line near 0 means the acceleration curve matches your hand. Rising to the right: fast moves carry too far.

    Paths, aligned to the target (target at right)

    Every move rotated so it runs left to right and scaled so the target sits at the dashed line. Loops past the line are overshoots.
